В рамках лабораторной работы были созданы репозиторий с основной веткой main и файл README.md . В каталоге lab-work-1/src/ разработаны скрипты на языке Python для решения задач базового ввода/вывода, форматирования текста и циклической обработки данных. Все программные модули протестированы через интерпретатор Python

Закреплены фиксация изменений и ведение структуры репозитория и базового программирования на Python с оформлением технической документации.
