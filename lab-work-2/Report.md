Лабораторная работа 2
Типы данных Python. Приведение типов. Решение задач на работу с числовыми данными.

А1. Вычисления и типы выражений
При заданных width = 17 и height = 12.0:
1. width // 2 -> значение 8, тип int (целочисленное деление).
2. width / 2.0 -> значение 8.5, тип float (обычное деление с вещественным числом).
3. height / 3 -> значение 4.0, тип float (деление float на int всегда даёт float).
4. 1 + 2 * 5 -> значение 11, тип int (сначала выполняется умножение, затем сложение).

А2. Преобразование в целое десятичное число через int()
'123e' — нельзя, вызывает ValueError (некорректный строковый литерал для десятичного целого).
'91.4' — нельзя, вызывает ValueError (int() по умолчанию не преобразует строки с десятичной точкой).
 524.345  435345345311145345 — нельзя, вызывает OverflowError (результат возведения в степень выходит за пределы числа с плавающей точкой).
'7.1 + 4' — нельзя, вызывает ValueError (строка содержит выражение, а не число).
 '4' - 2 — нельзя, вызывает TypeError (операция вычитания не поддерживается между str и int).
 '4-2' — нельзя, вызывает ValueError (строка не является числовым литералом).
 '42' — можно, результат 42 (int).
 -12.12 — можно, результат -12 (int, отбрасывается дробная часть).
